# Dani Hill — Welcome E-Card

Animated wedding e-invitation for Dani Hill, Genting Highlands: wax-sealed envelope opens to reveal the welcome card, followed by Our Story, the estate plan, location and a register-interest form that sends to WhatsApp.

Single self-contained file: `index.html`. Photos and links are set in the `IMAGES` and `CONFIG` lists near the bottom of the file.
